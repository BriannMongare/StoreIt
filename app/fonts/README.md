Place Poppins .woff2 files into this folder with the following names:

- Poppins-Thin.woff2 (100)
- Poppins-ExtraLight.woff2 (200)
- Poppins-Light.woff2 (300)
- Poppins-Regular.woff2 (400)
- Poppins-Medium.woff2 (500)
- Poppins-SemiBold.woff2 (600)
- Poppins-Bold.woff2 (700)
- Poppins-ExtraBold.woff2 (800)
- Poppins-Black.woff2 (900)
- Poppins-Italic.woff2 (italic, 400)

Options to obtain them:
1. Download from Google Fonts (Poppins) and convert to .woff2 if needed.
2. Use a font provider or the font's license to obtain webfont files.
3. Install `@fontsource/poppins` and copy the `files` from `node_modules/@fontsource/poppins/files` into this folder.

After placing files, restart the dev server so Next.js picks up the local fonts.
